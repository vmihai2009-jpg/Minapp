Minapp

A Winamp-skinned player that follows Spotify and plays YouTube playlists. Unzip it and run it: no install, no admin rights.

Windows

Windows 10 or 11. Unzip, then run Minapp.exe.

Download for Windows

macOS

Apple silicon and Intel. Unzip, then right-click Minapp.app → Open (first time only). It offers to copy itself to Applications. Uninstall Minapp.command in the same folder removes it cleanly.

Download for Mac

Version 1.7.1. The first run downloads about 150 MB (Electron and Webamp) into the same folder. Everything stays in that folder.

What it does

  • Any Winamp skin. A skin library menu that fills itself: load a .wsz, drag one onto the player or copy it into the skins folder and it appears in the menu. The corner logo opens skins.webamp.org for more. Mini mode, always-on-top pin, 0.5× to 3× size.
  • Controls Spotify. Play, pause, skip, seek, volume, shuffle and repeat.
  • A playlist that works. See what is coming up, click a title to jump straight to it, scroll up to see what you played and click to go back.
  • YouTube too. Paste a playlist or video link, and hide the video window if you only want the sound.
  • Working equalizer (Windows). The 10 sliders shape Spotify live through Equalizer APO. The visualizer and Milkdrop move with the music.
  • Everyday polish. Taskbar buttons, tray menu, global hotkeys, snap to screen edges, remembers where you left it.

Get started

  1. Download the zip for your system and unzip it anywhere you can write to.
  2. Run the start file (the Mac needs right-click → Open the first time).
  3. Open the Spotify desktop app and play something. Minapp follows it.

Windows may show a blue "Windows protected your PC" screen the first time, because Minapp is a small unsigned program: click More info → Run anyway. Minapp then puts a Minapp shortcut on your Desktop and in the Start menu; start it from there and the message never comes back. To skip it entirely, right-click the zip → Properties → tick Unblock before unzipping.

The Spotify desktop app is required (not the web player). On Mac, macOS asks once whether Minapp may control Spotify. The Mac version does not have the Spotify equalizer or the visualizer yet, because macOS offers no system-audio capture without extra software.

Minapp is built on Webamp and Electron. Not affiliated with Spotify, Winamp or YouTube.
